One call per round, at the 7-minute mark. Before it, the card shows an expected lean only — a lean is never recorded and never counts in the record below. After the call, the win % is recomputed every refresh from the distance to the target line in units of remaining-time volatility, cross-checked against the market's own implied price.

Numbers are fetched server-side (Kalshi's API refuses browser requests) and served with this page. Spot: Coinbase for SOL/ETH/XRP and BTC. Kalshi settles the crypto contracts against CF Benchmarks RTI, so spot here is a close proxy, not the settlement print.
